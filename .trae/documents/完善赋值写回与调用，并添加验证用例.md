## 代码改动点
1) 赋值与自增自减
- VisitAssignExpr：支持多左值写回；实现对三类 LValue 的写回：
  - 标识符：作用域内查找并写回。
  - 索引：对 []interface{} 与 map[interface{}]interface{} 写回；map[string]interface{} 做字符串键写回；边界检查。
  - 选择器：
    - map[string]interface{} 与 map[interface{}]interface{} 的字段名访问；
    - 反射支持 struct 字段（导出字段）。
- VisitSelfAddExpr：在可写 LValue 上实现 ++/--（int64/float64），完成读-改-写。
- 辅助：
  - resolveLValue(expr) -> {kind: ident|index|selector, base, key/name}
  - setLValue(ref, value) 与 getLValue(ref) 封装各类容器/变量的读写。

2) 索引与选择器读取
- VisitIndexExpr：保持读取能力，完善 map[string]interface{} 与 struct slice 场景。
- VisitSelectorExpr：支持 map/struct 字段读取。

3) 函数调用
- VisitCallExpr：
  - 目标解析：标识符或选择器解析为函数对象（脚本函数或 Go 反射函数）。
  - 参数求值与反射调用；返回单值或切片（取首个为表达式值）。
- Go 绑定：提供 RegisterFunc(name string, fn any) API（挂到 Executor 或 GoScript）用于注入。

4) 类型系统与初始化
- typeFromText：识别 [] 后缀与 map<>，返回 VarTypeArray/VarTypeMap 与对应 Go 承载类型：[]interface{}、map[interface{}]interface{}。
- VisitVariableDeclaration：根据初始化器返回的数组/Map 调整变量实际类型与承载，避免与 TypeGo 矛盾；对基础数值做现有的整/浮/布尔/字符串转换。

5) 测试/示例用例

  - Case A：赋值与算术

  - Case B：数组索引读写
    func main() int { int[] arr = {1,2,3}; arr[1] = 5; return arr[1]; } => 5
